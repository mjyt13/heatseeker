# apps/ai — ИИ-сервис (этап W2-B)

Отдельный процесс, общается с ядром только по REST (`/api/v1` + `/internal/ai/*` по сервисному
токену). Провайдер модели — `openai-compatible` (локально развёрнутая лёгкая модель: ollama /
vLLM / llama.cpp), опционально Anthropic. Свой `.env` — ядро о моделях ничего не знает.

Агенты: суммаризатор материала, структуризатор наработок, Q&A по предмету (RAG на pgvector),
классификатор Drive-файлов, извлечение дедлайнов из текста задания.

Язык — Python (FastAPI) рекомендован, альтернатива Go — открытый вопрос №4 в
`docs/OPEN-QUESTIONS.md`.

Статус: **создаётся после MVP** (см. `docs/PLAN.md`, §10).
