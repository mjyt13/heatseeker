# Heatseeker — лог решений

Решения, принятые при планировании (2026-09-15). Изменение решения — новая строка со ссылкой на
отменяемую, а не правка старой. Крупные архитектурные решения дополнительно оформлены в
[`adr/`](adr/).

| # | Решение | Обоснование |
|---|---|---|
| D1 | Монорепо: pnpm workspaces + Turborepo для JS; Go-модуль в `apps/api`; Python в `apps/ai` ([ADR-0001](adr/0001-monorepo.md)) | общие типы/клиент/UI, один CI, малая команда |
| D2 | Бэкенд — Go, REST + OpenAPI (chi + huma, sqlc + pgx, goose) ([ADR-0002](adr/0002-go-backend.md)) | скорость обработки, низкие требования к серверу, простой деплой |
| D3 | Redis: очереди (asynq), pub/sub для realtime, кеш — фоновая работа не грузит Postgres ([ADR-0006](adr/0006-redis-jobs-and-pubsub.md)) | мощности под Redis будут; БД — только для данных |
| D4 | Mobile — Expo; веб — Vite + React; общий UI — Tamagui ([ADR-0005](adr/0005-tamagui-universal-ui.md)); фолбэк NativeWind + shadcn только при провале настройки | единый UI, производительность |
| D5 | Хранилище — MinIO (S3 API); провайдер `local` для минимального сервера | самостоятельный хостинг |
| D6 | Медиа в трёх режимах LINK / CACHE / IMPORT, TTL и лимиты настраиваемые ([ADR-0003](adr/0003-media-two-modes.md)) | ресурсы сервера не гарантированы, файлы тяжёлые |
| D7 | Google Drive — сервисный аккаунт, индексация чужой общей папки; студенты выкладывают нативно | Диск чужой, никаких OAuth-экранов |
| D8 | Auth — своя, три уровня: имя → защищённый аккаунт → Google (только для загрузки на Диск); email опционален; публичное чтение L0 — выключенный переключатель ([ADR-0004](adr/0004-light-auth-tiers.md)) | быстрый вход, группа ~20 человек |
| D9 | Вступление — открытое по ссылке; `join_policy` для закрытой схемы | фундамент под будущее |
| D10 | Мультироли на членстве (массив ролей) | «староста = владелец + студент» |
| D11 | Обсуждения (threads) с личным и модераторским скрытием; заменяют комментарии; навигация по предмету — треды по занятиям позже, внутри предмета | новая фича, DRY; люди ищут по предмету |
| D12 | Единый журнал `group_events` (seq) для realtime, офлайн-синка и активности | один механизм вместо трёх |
| D13 | Офлайн-сообщения через `client_id` + outbox; кеш чтения обязателен; загрузка файлов только онлайн | «как в Telegram» |
| D14 | Realtime (WS + SSE) — этап W2-0, сразу после MVP, обязательно | чтение сообщений при включённых уведомлениях |
| D15 | Mute уведомлений по теме на настраиваемое время; для ДПО уведомления выключены по умолчанию | |
| D16 | ДПО — отдельная группа `kind=DPO` в той же системе | изолированный поток, та же логика |
| D17 | ИИ — отдельный сервис через API; провайдер openai-compatible, локальная лёгкая модель | изоляция, self-hosted |
| D18 | Экстракторы текста: pdf, docx, pptx, xlsx, rtf, odt, txt, md, csv | |
| D19 | Антивирус ClamAV опционально + обязательные проверки без AV | безопасность при неизвестных ресурсах |
| D20 | Markdown разрешён везде; i18n с этапа 0, ru основной, en каркас | |
| D21 | Задачи создаёт любой участник; закрепляет староста/модератор/админ | |
| D22 | Расписание: прямое редактирование старостой/админом + лог в MVP; запросы/утверждение — конец этапа 3 | |
| D23 | Свой материал: архивировать всегда, удалять до первого скачивания; роль GUEST есть; преподаватель как пользователь — нет | |
| D24 | Файлы: 200 MB/файл, allowlist типов, квота на группу настраиваемая | |
| D25 | Дистрибуция — Android APK (EAS Build); iOS — если появится Apple Developer | |
| D26 | Код English; коммиты и UI Russian (+ английские термины); SOLID / DRY / KISS / GoF в точках расширения | |
| D27 | Репозиторий самодостаточен: без ссылок на посторонние проекты | |
| D28 | `join_policy=APPROVAL` — не в первой версии; MVP — OPEN / INVITE; модель и эндпоинты готовы к APPROVAL | не усложнять вступление сейчас |
| D29 | Сервисный аккаунт получает права **Редактор** на общую папку Диска (индексация + возможность публиковать файлы от имени сервиса); все остальные пользователи работают с Диском через приложение только на чтение | один аккаунт с правами записи проще контролировать |
| D30 | ИИ-сервис (`apps/ai`) — Python (FastAPI) | экосистема локальных моделей, эмбеддингов, транскрибации |
| D31 | В сообщениях коммитов нет строк авторства ИИ-агента (`Co-Authored-By`, `Claude-Session`); исключение — первый коммит | пожелание автора |
| D32 | Загрузка на Google Диск из приложения входит в MVP — способ A (через сервисный аккаунт, `FEATURE_DRIVE_UPLOAD`); закрывает открытый вопрос №1 (2026-09-16). Публиковать может любой участник, кроме GUEST, с защищённым аккаунтом (`drive.upload`, как в `AUTH_REQUIRE_SECURED_FOR`) | решение автора; файл на Диске подписан «Загрузил: <имя>» |
| D33 | Вступление в группу — поиском по названию и сразу, без заявки (группы видны в поиске все); код/ссылка — дополнительный путь внизу экрана | приложение пока для одной группы, аудитория узкая; `join_policy` позволит закрыть доступ позже (2026-09-17) |
| D34 | Публикация на Диск в «Мой диск» обычного Gmail — через OAuth одного «публикующего» Google-аккаунта (староста): refresh-токен в БД (AES-GCM, `APP_ENCRYPTION_KEY`), файлы в его квоте; сервисный аккаунт остаётся для индексации. В перспективе — несколько подключений Диска на группу (разные аккаунты/папки) | Workspace-диска нет; рабочий диск группы — личный аккаунт с большим тарифом (закрывает открытый вопрос №6, 2026-09-17) |
