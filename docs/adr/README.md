# ADR — Architecture Decision Records

Короткие записи о значимых архитектурных решениях: что решили, почему, что отвергли, какие
последствия. Один файл — одно решение, нумерация сквозная, файлы не редактируются задним числом:
если решение меняется — новый ADR со ссылкой «заменяет ADR-NNNN».

## Шаблон

```markdown
# ADR-NNNN: <название>

Дата: YYYY-MM-DD · Статус: предложено | принято | заменено ADR-MMMM

## Контекст
Какая проблема или потребность.

## Решение
Что делаем.

## Альтернативы
Что рассматривали и почему отклонили.

## Последствия
Плюсы, минусы, что становится сложнее/проще, что нужно помнить.
```
