# infra/scripts — служебные скрипты

- `dev-ip.sh` (`task dev:ip`) — прописывает IP компьютера в локальной сети в dev-конфиги, чтобы
  телефон в той же сети достучался до API, MinIO и Metro (README, «На телефоне»).

Планируется: bootstrap бакета MinIO (создание, lifecycle для `tmp/`), бэкапы (`pg_dump` +
`mc mirror`), восстановление, генерация секретов для `.env`, проверка окружения перед деплоем.

Статус: создаётся на этапах 0 и 6.
