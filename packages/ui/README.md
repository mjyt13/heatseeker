# packages/ui — универсальные UI-компоненты

Tamagui-компоненты и тема, общие для `apps/mobile` (Expo) и `apps/web` (Vite). Здесь же —
дизайн-токены (цвета, отступы, типографика) и примитивы: кнопки, чипы-теги, карточки материалов/
задач/сообщений, списки, формы.

См. `docs/adr/0005-tamagui-universal-ui.md` (включая план отката на NativeWind + shadcn).

Статус: создаётся на этапе 0.
