# packages/shared — общие enum'ы, матрица прав, константы

**Генерируется из Go** командой `heatseeker gen` (`apps/api/internal/authz`, `internal/domain`)
и коммитится. Не редактировать руками: источник правды — Go.

Содержимое: enum'ы (роли, статусы, типы уведомлений, режимы медиа), матрица прав
`permissions.json` + типизированный `can(roles, action)`, константы (лимиты, пресеты mute,
offsets дедлайнов).

Статус: создаётся на этапе 0.
